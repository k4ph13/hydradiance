01 · Brand Identity

Who Skin Fluent Is

Skin Fluent by Nicole is a virtual skin coaching brand founded by Nicole, a licensed advanced esthetician with nearly 20 years of experience including 15+ years at Caesars Palace Qua Baths & Spa in Las Vegas. The brand is built around one idea: that your skin has a language, and with the right guidance, you can learn to speak it.

The tone is expert but warm — like a brilliant friend who happens to be a skincare professional. Not clinical, not spa-fluffy. Authoritative and accessible. Think: clean, structured, slightly luxurious.

04 · Quiz Integration

Embedding the Skin Quiz

The quiz is a self-contained HTML file (skinfluent_quiz_v4.html). It has all CSS and JS embedded — no external dependencies except Google Fonts.

Option A — Dedicated Page (Recommended)
Host the quiz HTML file at /quiz or /skin-quiz. This gives it a full-page experience with no nav distractions, which increases completion rates. The file can be served directly or its contents placed inside a minimal wrapper page.
Option B — iFrame Embed
Embed using an iFrame on any page: <iframe src="/quiz.html" width="100%" height="800px" frameborder="0"></iframe>. Adjust height as needed. Works but full-page is better for mobile.
Email Platform Connection
The quiz captures emails via a submitEmail(email, profileKey) function at the bottom of the HTML file. Wire this to your email platform's API (ConvertKit, Flodesk, or Mailchimp):

ConvertKit: POST to https://api.convertkit.com/v3/forms/{form_id}/subscribe with email + tag matching profile key
Flodesk: POST to Flodesk API with segment matching profile key
Mailchimp: POST to Mailchimp API with tag matching profile key

Profile keys: dry · oily · sensitive · acne · pigment · aging · rosacea
Each key triggers the matching delivery email with the correct PDF attached or linked.

07 · Copy & Tone

How the Site Should Sound

Every word on the site should sound like Nicole — knowledgeable, warm, direct, and never condescending. Here are a few principles to guide any copy written for the site:

✓ Do this
Speak directly to the reader's frustration ("You've tried everything. Your skin still isn't cooperating.")
Use specific, confident language ("8–12 weeks of consistency")
Position Nicole as a trusted expert, not a salesperson
Lead with the client's transformation, not Nicole's credentials
Use "your skin" language throughout — personalized, not generic
✗ Avoid this
Vague wellness language ("glow up," "skin journey," "radiant you")
Overpromising results ("guaranteed clear skin in 30 days")
Spa-fluffy tone that undersells the clinical expertise
Listing Nicole's credentials before establishing the client's problem
Using "I" before "you" — the site is for the reader, not about Nicole
